控制安全规则

如果主程序尚未发布运行时快照，本页面绝不把磁盘参数显示为“已生效”。角速度量程由 IMU 固件决定，这里的配置只负责解码。

官方总线 IMU ID 200 输入为带符号 i16 原始计数，解码器统一输出 rad/s；更换比例不影响四元数解算和安装方向。

IMU 数据换算与方向

gyro_rad_s = raw / counts × π / 180
请选择与 MCU 固件真实输出契约一致的比例；本界面不会改变传感器 FS 寄存器。特别是 /16.4 并非 ST LSM6DSV16X 标准 ±2000°/s 灵敏度。

面向实体鸭子的使用步骤

约束：不写舵机 EEPROM
确认硬件协议。官方 DXL2 IMU（ID 200）的 12 字节块包含 6 字节陀螺仪原始计数、6 字节 SFLP 四元数。若 MCU 实际输出的是 °/s 或 rad/s 而非原始计数，必须先改变解码契约，不能直接选 /16.4。
安装修改后的官方 robotd。先在 macOS/Linux 开发机用对应版本的补丁构建并运行 cargo test，采用官方签名更新方式部署。不能直接用旧 daemon 读取新配置。
通过 SSH 安全访问面板。在板端执行 sudo python3 web/calibration_web.py --target daemon-v0.17.8；开发机运行 ssh -L 8765:127.0.0.1:8765 user@board-ip，浏览器打开 http://127.0.0.1:8765。
确认运行快照。总览查看 `robotd` 真实生效的数据：版本、比例、IMU mount、15 关节映射。如显示“未验证”，不要相信任何被声称生效的数字。
选择 IMU 模式。标准固件保持 `st_500dps`。只有通过原始读数实验确认输出 `raw / 16.4` 时，选择 `custom_raw_div_16_4`。面板的单位必须保持 rad/s。
校准关节或 IMU 安装方向。建议先通过只读 `duck_calibrate.py record` 和五姿态计算生成数据，必要时再调整关节角度偏差；尽量不直接人工猜偏移。
预览、确认与提交。核对所有 15 关节、四元数和转换方式；写入会自动备份，但不会执行电机运动或自动重启。
安全重启及验收。托住鸭子、卸力，重启 `robotd`；刷新界面确认“已保存 = 已生效”。再观测连续 IMU、总线丢帧、舵机角度、动作和姿态稳定性。
“运行时快照”由实际 Rust DynamixelIo/IMU decoder 内存参数生成，写入路径为 `/run/robotd/calibration-effective.json`。配合 `robotctl monitor` 展示控制程序输出的真实陀螺仪速度。Web 仅绑定 localhost，外网访问必须由 SSH 隧道转发。
